# Historical beUI project index pilot

The pilot shipped in commit `2c14e20`. It scoped adapted public beUI buttons,
badges and navigation to `/projects`, retained Base UI overlays and saved the
prior cross-page draft as a recoverable Git stash.

The global Neutral design supersedes this pilot. There is no active beUI
registry, Motion dependency, parallel theme, or adapted runtime component.
See [Neutral UI delivery](neutral-ui.md) for the replacement and verification.

notice and adaptations remain in the Git history of the pilot commit.
