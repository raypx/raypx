# @voidmix/storage

## Purpose

Server-only object transport for API uploads and Worker deliverables.

## Interface

`src/index.ts` exports S3, filesystem, and memory implementations of the
Core-owned `ObjectStorage` port. Credentials are injected by composition roots.

## Ownership

- Private object transfer, bounded signatures, checksum verification and deletion.
- Local implementations for explicit development and isolated tests.

## Constraints

- Never import DB, Application, HTTP sessions, React, or frontend applications.
- Application owns upload intents, permissions and publication; a stored object
  is not a published asset.
- Never log signed URLs, credentials, object contents or request headers.
- Object keys are generated by Application and checked before transport.

bun run --cwd packages/storage check
