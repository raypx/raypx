# @raypx/provider-pi

Injected Pi SDK session adapter. CLI owns policy, files, processes, credentials and SQLite.
Export the session, bounded SDK loop and transcript schema through explicit entries.
Persist tool intent before effects and results before inference. Cancellation drains all work.
Never replay unresolved effects or expose reasoning, tool arguments or raw errors as activity.
Run package checks, SDK/adapter tests and CLI integration tests, then repository verify.
