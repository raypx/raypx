# @raypx/ui

React presentation components and styles. Implements Button, ConnectionStatus, and styles.css. Components do not initiate requests, read environment, or depend on routing. React is peer dependency.

Public entrypoint: `@raypx/ui`. Import via package exports, cross-package direct access to src or dist prohibited.

Runtime outputs ESM and TypeScript declarations. Static TypeScript configuration provided by @raypx/tsconfig, tasks provided by @raypx/config; build uses tsconfig.json, source/test/config checks use tsconfig.test.json, task definitions in this package's vite.config.ts.
